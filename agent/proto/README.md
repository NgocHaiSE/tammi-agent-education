# Proto Generation

This directory contains Protocol Buffer definitions and generated code for gRPC services.

## Files

- `agents.proto` - Main service definition for Agent API
- `generate_stubs.py` - Script to generate Python code from .proto files
- `agents_pb2.py` - Generated protobuf message classes (auto-generated, do not edit)
- `agents_pb2_grpc.py` - Generated gRPC service classes (auto-generated, do not edit)
- `agents_pb2.pyi` - Generated type hints for IDE support (auto-generated, do not edit)

## Usage

### Manual Generation (Development)

To regenerate the Python stubs from proto files:

```bash
# From project root
python agent/proto/generate_stubs.py

# Or use the convenience script
python scripts/generate_proto.py
```

**Requirements:** 
- `grpcio-tools` must be installed: `pip install grpcio-tools`

### Automatic Generation (Docker)

When building the Docker image, proto stubs are automatically generated during the build process:

```bash
docker build -t tammi-agent-medical .
```

The Dockerfile includes a step that runs `generate_stubs.py` to ensure generated code is always fresh and matches the proto definitions.

## What the Script Does

The `generate_stubs.py` script:

1. **Generates Python code** from `.proto` files using `grpc_tools.protoc`
2. **Creates three files** for each proto:
   - `*_pb2.py` - Message classes
   - `*_pb2_grpc.py` - Service classes
   - `*_pb2.pyi` - Type hints
3. **Automatically fixes imports** - Changes absolute imports to relative imports in `*_grpc.py` files for better compatibility
4. **Reports success/failures** - Clear output showing what was generated

## Import Fix

The script automatically fixes imports in generated `*_grpc.py` files:

**Before (generated by protoc):**
```python
from agent.proto import agents_pb2
```

**After (fixed by script):**
```python
from . import agents_pb2
```

This ensures the code works correctly in both development and production environments without PYTHONPATH issues.

## Adding New Proto Files

To add a new proto file:

1. Create your `.proto` file in this directory
2. Add the filename to the `proto_files` list in `generate_stubs.py`:
   ```python
   proto_files = [
       "agents.proto",
       "your_new_file.proto",  # Add here
   ]
   ```
3. Run the generation script
4. Import will be automatically fixed

## Troubleshooting

**Error: `ModuleNotFoundError: No module named 'grpc_tools'`**
- Install grpcio-tools: `pip install grpcio-tools`

**Error: `File does not reside within any path specified`**
- Make sure you run the script from the project root
- The script automatically detects paths, so this should not occur

**Import errors when using generated code:**
- The script should automatically fix imports
- If issues persist, check that `agents_pb2_grpc.py` uses `from . import agents_pb2`
- Re-run the generation script

## Notes

- Generated files are marked with `# DO NOT EDIT!` comments
- Always regenerate after modifying `.proto` files
- The Docker build process ensures production images always have fresh generated code
- Type hints (`.pyi` files) improve IDE autocomplete and type checking
